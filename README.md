
# Reserve Juggler

A four-tier algorithmic treasury management prototype.

## Technology Stack
- Python
- Pandas and NumPy
- Scikit-learn
- SciPy
- Streamlit and Plotly
- Pytest

## Setup
Create and activate a virtual environment, then install dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-lock.txt
```
